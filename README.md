# 임베디드 자율주행 자동차

**직접 수집한 주행 이미지로 CNN을 학습하고 Raspberry Pi 자동차의 조향에 적용한 프로젝트입니다.** 카메라로 트랙을 따라 주행하며 시계 객체를 인식하면 정지합니다.

2024년 2학기 · 임베디드응용 및 실습

Python · TensorFlow/Keras · OpenCV · Raspberry Pi GPIO

<img src="docs/images/track.png" alt="실내 트랙을 주행하는 자율주행 자동차" width="220" />

## 수행한 작업

- 차량을 직접 조종하며 **카메라 이미지와 주행 방향을 수집**했습니다.
- 수업에서 제공한 CNN을 수집 데이터로 학습하고 직진·좌회전·우회전 제어에 적용했습니다.
- OpenCV 객체 인식과 모터 정지, 방향별 LED 표시를 연결했습니다. 정지 지연을 줄이기 위해 목표 객체만 화면에 표시하도록 수정했습니다.
